# Arena

一个基于 Vite 和 React 搭建的前端项目，用于展示直播运营场景下的智能助手工作台，覆盖智能撮合、智能触达、流量诊断、教育物料生成等功能模块。

## 功能概览

- 智能撮合：为主播生成更合适的 PK 匹配建议
- 智能触达：围绕召回、提醒和分层运营提供触达方案
- 流量诊断：分析直播间曝光、进房、停留和转化问题
- 教育物料：生成培训提纲、活动文案和运营物料

## 技术栈

- React 18
- Vite 5
- JavaScript
- CSS

## 本地开发

安装依赖：

```bash
npm install
```

启动开发环境：

```bash
npm run dev
```

构建生产版本：

```bash
npm run build
```

本地预览构建结果：

```bash
npm run preview
```
